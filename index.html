      PART 7　規約のために

      このやり方を守る理由と、守ること

      投稿、いいね、フォローの自動化は、アカウント停止や報酬取り消しにつながるおそれ。このガイドは、そこに踏み込まない設計です。

      しないこと

      • 投稿、いいね、フォロー、コメントの自動実行（ブラウザ操作や拡張機能も含む）
      • 楽天のサイトから、情報を抜き取ること
      • 他人の投稿、商品説明、レビューを写すこと
      • 楽天の商品画像を、保存して使うこと
      • アフィリエイトリンクを自分で作る、変える、送る
      • 使ったことがあるかのような表現（「使ってみた」「愛用」「買って良かった」など）
      • 複数アカウントの運用、家族や友人への購入の依頼

      守ること

      • 投稿文は120〜200文字、ハッシュタグは最大3つ
      • 最後に【PR】を入れる
      • 商品の種類、価格、レビューなど、取得した事実だけを書く
      • 渡した情報にない数字、効果、順位は書かない
      • 「最高」「No.1」「絶対」などの断定は使わない
      • 他の商品との比較や、悪く言う表現はしない
      • 画像は、文字を入れず、商品の実物を描かない、イメージ画像にする

      体や肌への効果を語る表現は、薬機法という法律に触れるおそれ。このキットは、医薬品、サプリ、化粧品、健康器具を候補から外す設定です。迷ったときの合言葉は、「取得した事実だけを、使ったかのように書かずに伝えているか」。

def load_env():
    p = BASE / ".env"
    if not p.exists():
        return
    for line in p.read_text(encoding="utf-8").splitlines():
        line = line.strip()
        if not line or line.startswith("#") or "=" not in line:
            continue
        k, v = line.split("=", 1)
        os.environ.setdefault(k.strip(), v.strip().strip('"').strip("'"))


def seen_codes():
    s = set()
    if HISTORY.exists():
        for line in HISTORY.read_text(encoding="utf-8").splitlines():
            code = line.split("\t")[0].strip()
            if code:
                s.add(code)
    return s


def call_api(url, genre, page):
    q = {
        "applicationId": os.environ["RAKUTEN_APP_ID"],
        "accessKey": os.environ["RAKUTEN_ACCESS_KEY"],
        "genreId": genre,
        "page": page,
        "formatVersion": 2,
        "elements": ELEMENTS,
    }
    req = urllib.request.Request(
        url + "?" + urllib.parse.urlencode(q),
        headers={"Referer": os.environ["RAKUTEN_REFERER"]},
    )
    try:
        with urllib.request.urlopen(req, timeout=30) as r:
            data = json.loads(r.read().decode("utf-8"))
    except urllib.error.HTTPError as e:
        body = e.read().decode("utf-8", "replace")[:200]
        raise ApiError("ジャンル%sで取得に失敗しました 状態%s %s\n%s" % (genre, e.code, body, HINTS.get(e.code, "")))
    except urllib.error.URLError as e:
        raise ApiError("ネットワークに接続できませんでした %s" % e.reason)
    time.sleep(1.5)  # 公式の注意に合わせて、続けて呼びすぎない
    return [i.get("item", i) for i in data.get("items", [])]


def fetch():
    load_env()
    miss = [k for k in ("RAKUTEN_APP_ID", "RAKUTEN_ACCESS_KEY", "RAKUTEN_REFERER")
            if not os.environ.get(k) or "ここに" in os.environ.get(k, "")]
    if miss:
        print("未設定の項目があります " + ", ".join(miss))
        print(".envファイルを開いて、値を入れてください。")
        sys.exit(2)

    genres = [g.strip() for g in os.environ.get("GENRE_IDS", "215783,558944,551167,100227").split(",") if g.strip()]
    per_genre = int(os.environ.get("PER_GENRE", "3"))
    max_pages = int(os.environ.get("MAX_PAGES", "3"))
    min_review = float(os.environ.get("MIN_REVIEW", "4.0"))
    url = os.environ.get("RAKUTEN_API_URL") or DEFAULT_URL

    seen = seen_codes()
    picked, errors = [], []
    codes_now = set()
    for g in genres:
        got = 0
        for page in range(1, max_pages + 1):
            if got >= per_genre:
                break
            try:
                items = call_api(url, g, page)
            except ApiError as e:
                errors.append(str(e))
                break
            if not items:
                break
            for it in items:
                if got >= per_genre:
                    break
                code = it.get("itemCode")
                if not code or code in seen or code in codes_now:
                    continue
                if str(it.get("availability", "1")) == "0":
                    continue
                rv = it.get("reviewAverage")
                if rv not in (None, "") and float(rv) < min_review:
                    continue
                codes_now.add(code)
                got += 1
                picked.append({
                    "idx": len(picked) + 1,
                    "code": code,
                    "name": it.get("itemName", ""),
                    "price": it.get("itemPrice"),
                    "url": it.get("itemUrl", ""),
                    "shop": it.get("shopName", ""),
                    "rate": it.get("affiliateRate", ""),
                    "review_avg": it.get("reviewAverage", ""),
                    "review_count": it.get("reviewCount", ""),
                    "genre": g,
                })

    for e in errors:
        print(e)
    if not picked:
        print("候補を取得できませんでした。")
        sys.exit(1)

    TODAY.mkdir(exist_ok=True)
    (TODAY / "candidates.json").write_text(json.dumps(picked, ensure_ascii=False, indent=1), encoding="utf-8")
    print("番号\t商品名\t価格\t料率\tレビュー\tショップ")
    for c in picked:
        rv = "%s(%s件)" % (c["review_avg"], c["review_count"]) if c["review_avg"] != "" else "なし"
        rate = c["rate"] if c["rate"] != "" else "-"
        print("%d\t%s\t%s円\t%s\t%s\t%s" % (c["idx"], c["name"][:42], c["price"], rate, rv, c["shop"]))


def mark(status, nums):
    f = TODAY / "candidates.json"
    if not f.exists():
        print("先に fetch を実行してください。")
        sys.exit(1)
    cands = {c["idx"]: c for c in json.loads(f.read_text(encoding="utf-8"))}
    now = datetime.date.today().isoformat()
    lines = []
    for n in nums:
        c = cands.get(int(n))
        if not c:
            print("番号%sは候補にありません" % n)
            continue
        lines.append("%s\t%s\t%s\t%s" % (c["code"], now, status, c["name"]))
    if lines:
        with HISTORY.open("a", encoding="utf-8") as h:
            h.write("\n".join(lines) + "\n")
    print("%d件を記録しました（%s）" % (len(lines), status))


def copy_text(t):
    name = platform.system()
    try:
        if name == "Darwin":
            subprocess.run(["pbcopy"], input=t.encode("utf-8"), check=True)
            return True
        if name == "Windows":
            subprocess.run(["clip"], input=b"\xff\xfe" + t.encode("utf-16le"), check=True)
            return True
        for cmd in (["wl-copy"], ["xclip", "-selection", "clipboard"], ["xsel", "--clipboard", "--input"]):
            if shutil.which(cmd[0]):
                subprocess.run(cmd, input=t.encode("utf-8"), check=True)
                return True
    except Exception:
        return False
    return False


def clip(n):
    f = TODAY / "posts.txt"
    if not f.exists():
        print("today/posts.txt がまだありません。")
        sys.exit(1)
    blocks = [b.strip() for b in re.split(r"(?m)^=====\s*$", f.read_text(encoding="utf-8")) if b.strip()]
    if n < 1 or n > len(blocks):
        print("投稿文は全部で%d本です。" % len(blocks))
        sys.exit(1)
    text = blocks[n - 1]
    ok = copy_text(text)
    print(text)
    print("\n" + ("クリップボードにコピーしました。ROOMアプリに貼り付けてください。"
                  if ok else "自動コピーできませんでした。上の文章を選んでコピーしてください。"))


def image(n, prompt):
    """OpenAIの画像生成APIで、イメージ画像を作ります（.env の OPENAI_API_KEY が必要）。"""
    import base64
    load_env()
    key = os.environ.get("OPENAI_API_KEY", "")
    if not key or "ここに" in key:
        print("OPENAI_API_KEY が未設定です。.envに入れると、画像を作れます。画像なしでも、投稿文は使えます。")
        sys.exit(2)
    model = os.environ.get("OPENAI_IMAGE_MODEL", "gpt-image-1")
    size = os.environ.get("OPENAI_IMAGE_SIZE", "1024x1024")
    url = os.environ.get("OPENAI_API_URL") or "https://api.openai.com/v1/images/generations"
    body = json.dumps({"model": model, "prompt": prompt, "size": size, "n": 1}).encode("utf-8")
    req = urllib.request.Request(url, data=body, headers={
        "Content-Type": "application/json", "Authorization": "Bearer " + key})
    try:
        with urllib.request.urlopen(req, timeout=180) as r:
            data = json.loads(r.read().decode("utf-8"))
        item = data["data"][0]
        if item.get("b64_json"):
            raw = base64.b64decode(item["b64_json"])
        else:
            with urllib.request.urlopen(item["url"], timeout=60) as r2:
                raw = r2.read()
    except urllib.error.HTTPError as e:
        print("画像の生成に失敗しました 状態%s %s" % (e.code, e.read().decode("utf-8", "replace")[:200]))
        print("APIキー、利用の条件、残高を、OpenAIの画面で確認してください。")
        sys.exit(1)
    except (urllib.error.URLError, KeyError, IndexError, ValueError) as e:
        print("画像の生成に失敗しました %s" % e)
        sys.exit(1)
    TODAY.mkdir(exist_ok=True)
    out = TODAY / ("image_%d.png" % n)
    out.write_bytes(raw)
    print("%s に保存しました" % out.relative_to(BASE))


def main():
    if len(sys.argv) < 2:
        print(__doc__)
        return
    cmd = sys.argv[1]
    if cmd == "fetch":
        fetch()
    elif cmd in ("shown", "done"):
        mark("表示済み" if cmd == "shown" else "投稿済み", sys.argv[2:])
    elif cmd == "clip" and len(sys.argv) >= 3:
        clip(int(sys.argv[2]))
    elif cmd == "image" and len(sys.argv) >= 4:
        image(int(sys.argv[2]), " ".join(sys.argv[3:]))
    else:
        print(__doc__)


if __name__ == "__main__":
    main()

      # 楽天ROOM 投稿準備フォルダのルール

このフォルダでは、楽天ROOMの投稿準備だけを手伝います。
投稿そのものは、必ず本人がROOMアプリで手作業します。

`/room` と入力されたときも、「今日の投稿を作って」「今日の分」「投稿の準備」のように話しかけられたときも、同じ流れで進めます。
流れは `.claude/commands/room.md` の6つの手順です。毎回、先頭の手順から順番に実行します。
途中で本人に質問はしません。予約実行（run_daily.sh、run_daily.bat）で呼ばれたときも、同じです。
投稿そのものは、本人がROOMアプリで行います。

## 絶対にしないこと
- ROOMへの投稿、いいね、フォロー、コメントの自動実行（ブラウザ操作、画面操作、Claude in Chrome、拡張機能、スクリプトを使う方法を含む）
- 楽天のサイトから情報を抜き取ること（情報の取得は、公式APIの `room_tools.py fetch` だけ）
- 他人の投稿、商品ページの説明文、みんなのレビューを写すこと
- 楽天のページにある画像の、スクリーンショットやダウンロードの利用
- アフィリエイトリンクを作る、変える、メールやメッセージで送ること
- 使ったことがあるかのように書くこと（「使ってみた」「愛用」「買って良かった」「おすすめです」などの体験や推薦の表現）
- 複数アカウントの運用や、家族や友人に購入を頼む案内

## 画像の作り方
- 画像は、`room_tools.py image` で作る、イメージ画像だけ
- 文字を入れない。商品の実物は描かない。楽天の画像を参照したり、加工したりしない
- イラスト調で、やわらかい光にする

## 投稿文の書き方
- 1本は120〜200文字
- です・ます調に体言止めを混ぜて、語尾が続けて同じにならないようにする
- 最初の1文は、読んだ人の困りごとや関心から入る（例「作り置きの保存場所に困っている方へ」）
- 書いてよいのは、取得した事実だけ。商品の種類、セット内容、価格、レビュー平均、レビュー件数
- 商品ページの文章は写さず、渡された事実だけを自分の言葉で言い換える
- 渡された情報にない数字、効果、ランキング、受賞歴は書かない
- 病気や症状への効果、肌や体が変わるといった効能の表現は使わない
- 「最高」「No.1」「絶対」などの断定は使わない
- 他の商品や他社との比較、悪く言う表現はしない
- ハッシュタグは最大3つ
- ダッシュ記号や、飾りのコロンは使わない
- 「AではなくB」のような言い切りの型は使わない
- 末尾に【PR】の1行を付ける

## ファイル
- `room_tools.py` 候補の取得、記録、コピーを行う道具
- `.env` アプリID、アクセスキー、登録したWebサイトURL（外に出さない。チャットにも貼らない）
- `today/` 今日の候補と投稿文
- `history.txt` 表示済みの記録（同じ商品を何度も出さないため。自動で書き込まれる）

      よくある質問

      「403」と出て、候補が取れません

      原因で多いのは、アプリ登録で入れたURLと、.env の RAKUTEN_REFERER の不一致。最後のスラッシュまで、同じ文字にそろえます。アプリIDとアクセスキーの貼り間違いも、あわせて確認を。

      「429」と出ます

      短い時間にアクセスしすぎた状態。しばらく待ってから、もう一度 /room を実行。連続での実行は、避けてください。

      候補が少ない、出てきません

      表示済みの商品は記録で除かれるため、続けるほど候補は減少。GENRE_IDS にジャンル番号を足すか、MIN_REVIEW を少し下げると、候補が増えます。

      Pythonがないと言われました

      Claudeに「Pythonを入れる方法を教えて」と頼むのが近道。Windowsでは、python や py という名前で動く場合があります。

      コピーがうまくいきません

      クリップボードへのコピーは、Windowsでの動作が未確認。うまくいかないときは、画面に出た文章か、today フォルダの posts.txt から、自分で選んでコピーしてください。

      使ったことがあるように書かれませんか

      書かれません。投稿文の材料は、取得した事実（商品の種類、価格、レビューの平均と件数）のみ。「使ってみた」「愛用」などの体験の表現は、入らない仕組みです。

      画像は、どんなものができますか

      商品の種類から連想する、雰囲気のイメージ画像。文字なし、商品の実物は描かず、イラスト調で、やわらかい光。条件を変えたいときは、キットの room.md の手順5を書き換えます。

      画像が作られません

      原因で多いのは、.env の OPENAI_API_KEY が未入力、またはOpenAI側の残高や利用条件の不足。画面に出た文は、そのままClaudeに見せてください。画像がなくても、投稿文までは作られる設計。

      予約の時間にパソコンが寝ていました

      予約が動くのは、その時刻にパソコンの電源が入っていて、スリープしていないときだけ。時間を変えたいときは、「予約の時間を朝6時に変えて」とClaudeに頼めば完了です。

      投稿文を直したいです

      画面の図は、キットの実際の出力をもとにした再現。商品名、ショップ名、ID、URLはすべて見本で、実在のものとは無関係です。
